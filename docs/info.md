## How it works

AND, NAND, and OR gates are connected to input and a input b.

16 flip flops are used to divide the clock speed with two outputs, one at the 12th flop and one at the 16th flop.

## How to test

Set the input truth table and check that outputs match the expected results.
Set the block to 10kHz and you should see the fifth output flashing quickly and the fourth flashing slowly.
